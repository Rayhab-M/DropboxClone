# Welcome to My Dropbox

---

## Task

The goal of this project is to create a Dropbox-like application using ReactJS and AWS Amplify. The application allows users to upload, manage, and preview files stored in AWS cloud storage.

Features:

- **User Authentication** – Powered by AWS Amplify Auth.
- **File Upload & Management** – Users can upload, delete, and organize files in folders.
- **File Preview** – View files in a new tab without downloading.
- **Shareable Links** – Generate and copy secure links for file sharing.
- **Profile Management** – Edit user profile details.

## Description

To build this application, we used ReactJS for the frontend and AWS Amplify for authentication and file storage. The UI provides an intuitive experience similar to Dropbox, allowing users to manage their files efficiently.

Technologies Used:

- **ReactJS** – Frontend UI development.
- **AWS Amplify** – Authentication & Storage.
- **React Router** – Navigation between pages.
- **CSS (Custom & Amplify UI Styling)** – Styling the UI components.
- **AWS S3 Storage** – Cloud-based file management.

## Installation

npm install to install missing dependencies.
npm install aws amplify/storage to install the storage
npm install react router-dom
npm start to run the application.

## Usage

Once the application is running, users can:

Sign In / Sign Up
Navigate to the login page.
Enter credentials or sign up for a new account.

Upload & Manage Files
Click on the Upload button to select and upload a file.
View a list of uploaded files in the Home section.
Click Preview to open a file in a new tab.
Click Delete to remove a file.

Profile Management
Navigate to the Profile page to edit user details.

Generate & Copy File Links
Click Copy Link to generate a shareable link, when you click on the link it downloads the file for you to preview and accesss the file
Paste the link in a browser to access the file.
